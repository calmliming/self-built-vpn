# Self VPN HTML 交互原型

当前正式设计入口是 `dist/index.html`。它已内联全部 CSS、JavaScript 和 SVG 图标，零外部依赖，可直接用浏览器打开。大圆角、胶囊按钮、白色表面、细边框和蓝色强调色已保留，无拟态、内阴影或厚重投影。

## 本地预览

在此目录运行：

```sh
python3 preview.py
```

打开终端打印的地址。默认仅监听 `127.0.0.1`，自动选择可用端口。可通过 `--port 8766` 指定端口，按 Ctrl+C 停止。预览只提供 `dist/`，不提供仓库内的环境文件或私钥。

## 页面与交互

- 总览：在线服务器、可用节点、订阅、待同步任务、各地区卡片。
- 服务器管理：添加与编辑连接参数、模拟连接测试和默认节点部署。
- 节点管理：地区与协议组合筛选、搜索、分页、详情与编辑。
- 订阅管理：新建、编辑授权、启停、复制示例链接、删除、按服务器同步详情和重试。
- 重置链接：更换下载地址，保留节点凭据版本。
- 重置全部凭据：同时更换链接与凭据版本，需确认客户端重新导入；离线地区保留待同步状态。
- 分流规则：手动选择、故障回退、延迟优选、地区排序、应用范围与示例配置下载。
- 诊断日志：模拟诊断、报告筛选；SSH 超时后其余检查显示“未执行”。
- 操作日志：筛选、任务详情、按服务器执行结果、CSV 导出；删除订阅仍保留日志和撤销任务。
- 系统设置：常规设置、安全偏好、本机备份、JSON 导入导出与恢复初始示例。

桌面通过右上角“设计原型 · 示例数据”切换香港在线/离线场景。小屏幕可展开导航，点击“示例场景”。恢复在线后，可在订阅或任务详情中重试同步。

## 数据范围

全部动作只修改浏览器中的示例状态，不执行 SSH、不部署服务、不修改真实 VPN 凭据。IP 使用文档示例地址，订阅链接使用 `vpn.example`。配置下载用于展示结构，不包含可用节点或真实密钥。

状态保存在当前浏览器的 localStorage（键 `self-vpn-html-prototype-v1`）。同一来源刷新后继续保留；换端口、换浏览器或直接打开文件可能使用独立存储。“系统设置 → 备份恢复 → 恢复初始示例”可清理体验数据。

## 维护

- `src/index.html`：页面骨架。
- `src/styles.css`：大圆角、扁平表面与响应式布局。
- `src/app.js`：示例状态、页面渲染和交互。
- `build.py`：生成可独立分发的 `dist/index.html`。
- `quality-review.json`：实际完成的验收记录。
- `preview/`：浏览器实拍截图。

修改源码后运行：

```sh
node --check src/app.js
python3 build.py
```

然后刷新预览。构建仅依赖 Python 3，Node 只用于可选的 JavaScript 语法检查。
